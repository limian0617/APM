# APM-023 G1 Baseline V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Freeze an approved project's G1 baseline V1 and expose it as an immutable, auditable planning snapshot.

**Architecture:** The Planning module owns source snapshot construction and a transactional baseline command. PostgreSQL owns the durable fact and its no-mutation enforcement; Next.js routes only authorize, parse and delegate through the existing idempotency boundary.

**Tech Stack:** Next.js Route Handlers, TypeScript, Prisma 6, PostgreSQL SQL migrations, Vitest.
